## Chung Do Association Portal

This is a portal for members of the Chung Do Association.

It currently provides event registration, payment, and associated data.

Planned additional features include:

- Wiki style system to become the official "word" on all aspects Chung Do Tae Kwon Do.  Entries to that system will need to be approved by X other SMEs


## Developer Notes

We're going to need some kind of API for mobile apps eventually. Check out [Lighthouse](https://lighthouse-php.com/). for Laravel/GraphQL integration
